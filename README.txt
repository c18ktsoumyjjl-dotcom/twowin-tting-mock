[TWOWIN 시안 페이지 사용법]  (띵벳 1918px 화면 실측 레이아웃)
1. 압축 풀고 index.html 더블클릭 (크롬 권장)
2. 이미지 교체 = 같은 파일명으로 덮어쓰고 새로고침
   casino/ slots/ sports/ evt/ : 게임 타일 PNG
   img/logo.png 로고, img/banner.png 메인배너(1336x238 권장)
   icons/cat-01.png~cat-10.png 카테고리 아이콘, icons/side-01.png~ 왼쪽 사이드 아이콘 (없으면 글자 표시)
3. 메뉴·게임 삭제/순서: 오른쪽 아래 [편집모드] → × 삭제, ◀ ▶ 순서, ▲ 섹션 위로 (브라우저에 자동 저장)
   [초기화]=원래대로, [설정 내보내기]=바뀐 config.js 다운로드 → 이 폴더 config.js에 덮어쓰면 영구 반영
4. 게임 추가: 폴더에 PNG 넣고 config.js 의 items 목록에 파일명 한 줄 추가
